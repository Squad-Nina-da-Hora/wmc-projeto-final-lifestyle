## Fluxo de trabalho

1. Atualizar a main
2. Criar sua branch de trabalho
3. Antes de commitar, limpar os outputs
4. Fazer os commits e enviar
5. Antes de fazer a Pull Request, atualizar a main
6. Voltar para sua branch e mesclá-la com a main
7. Se houver conflitos, resolvê-los se atentando para **não sobrescrever** o trabalho anterior
8. Abrir a Pull Request e marcar as demais como revisoras

Caso precise fazer alterações após a PR, não é necessário abrir uma nova.

## ⚙️ Como rodar o projeto

1. Clone o repositório

2. Instale as dependências:

  ``` bash
  pip install -r _dependencias.txt

  # OU

  pip install pandas jupyter ipykernel sklearn
  ```

3. Execute o Notebook:

- Abra `analise.ipynb` no VS Code
- Selecione o kernel no canto superior direito
- Execute tudo ou célula por célula

## 🚀 Tecnologias Utilizadas

- Python 3.x
- Pandas — manipulação e análise de dados
- Jupyter Notebook / Google Colab — ambiente interativo
- VS Code + extensões Python e Jupyter
